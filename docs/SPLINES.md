# Splines

This document evaluates the different types of splines and aims to present the reasoning behind the chosen path planning algorithm.

This planner evaluates three core mathematical curves: **Natural Cubic Splines**, **Catmull-Rom Splines**, and **B-Splines**.

---

## Spline Analysis

### 1. Natural Cubic Splines
Natural Cubic Splines are piecewise cubic polynomials that pass exactly through a given set of waypoints.

**Pros:**
- **C2 Continuity:** Guarantees continuous velocity and acceleration across the entire trajectory with no sudden jerks on the manipulator's motors.
- **Exact Interpolation:** The end-effector will perfectly hit every specified waypoint.

**Cons:**
- **Global Control:** Modifying a single waypoint requires recalculating the entire spline. If a dynamic obstacle forces a local path correction during execution, the entire planned trajectory changes, which can be computationally expensive and unpredictable.
- **Oscillation:** Can exhibit severe overshoot if waypoints are spaced unevenly or require sharp turns.

### 2. Catmull-Rom Splines
Catmull-Rom splines are a specific type of cubic Hermite spline. The tangent at each control point is calculated using the previous and next control points, ensuring a smooth curve that passes through all defined coordinates.

**Pros:**
- **Local Control:** Moving a waypoint only affects the adjacent curve segments. This makes it highly suitable for real-time recalculation in dynamic environments.
- **Exact Interpolation:** The end-effector will perfectly hit every specified waypoint.
- **No Linear System to Solve:** Computationally cheaper to generate on the fly than Natural Cubic splines.

**Cons:**
- **C1 Continuity:** The acceleration profile will have instantaneous jumps at the waypoints, which can cause vibrations or tracking errors in rigid industrial manipulators operating at high speeds.

### 3. B-Splines (Basis Splines)
B-Splines use a set of control points to guide the curve rather than forcing the curve to pass through them. The curve is a linear combination of basis functions determined by a knot vector.

**Pros:**
- **C2 Continuity:** Guarantees continuous velocity and acceleration across the entire trajectory with no sudden jerks on the manipulator's motors.
- **Local Control:** Moving a waypoint only affects the adjacent curve segments. This makes it highly suitable for real-time recalculation in dynamic environments.
- **Convex Hull Property:** The curve is entirely contained within the convex hull of its control points. If the control points' convex hull does not intersect an obstacle, the manipulator is mathematically guaranteed not to collide with it.

**Cons:**
- **Approximate Waypoint Traversal:** The robot does not pass through the specified waypoints without using multiple overlapping knots to force interpolation.

## High-Level Comparison Matrix

| Feature | Natural Cubic Spline | Catmull-Rom Spline | B-Spline | 
| :--- | :--- | :--- | :--- |
| **Waypoint Traversal** | Interpolation | Interpolation | Approximation |
| **Continuity** | C2 | C1 | C2 |
| **Control Scope** | Global | Local | Local |

---

## Conclusion

After evaluating the above specified properties of each spline, the best outcome was to use a hybrid spline planner. The required properties the planner must possess are local control, C2 continuity and exact interpolation in the same priority order. Therefore, the decision to implement a hybrid planner including Catmull-Rom interpolation with B-spline planning was chosen.

**Pros:**
- The multiple waypoints generated by the Catmull-Rom interpolation method are closely located, ensuring B-spline trajectory is quite constrained within the path limits with little deviation.
- The B-spline trajectory generated ensure no sudden jerks for the manipulator and smooth acceleration.
- Local control of the planner ensures both static and dynamic planning.
